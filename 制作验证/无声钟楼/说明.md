## 风味结论与制作纲领

**作者确认的优先约束：什么都能复杂，人物不能复杂；人物不拿着武器。**后续人物只采用圆点、朝向、名称与状态，不画肢体、头盔、披风或手持装备。装备说明用独立图卡/事件，不挂接在人物上。地形、任务与镜头可以丰富；人物逻辑采用独立圆形代理，位置、朝向、状态与画面分层，保证能接自动寻路。下文旧建议若与此冲突，以本条为准。

可借鉴的核心是：**把一场有明确目标的行动，做成观众能看懂因果的战场记录；专业分工创造优势，敌人的回应制造变化，代价留在下一次行动里。**

1. **战场先于解说。** 观众先看见门、路线、队形、目标与危险的关系，再通过短句获得必要解释。胜负原因必须在地图动作中出现。
2. **准备有回报。** 侦察、预留通路、守住入口、接替位置等安排，后面必须影响局面。每个重要道具都要有使用条件与回收时刻。
3. **敌人会应对。** 对手会绕路、等待、追击、撤回或保护目标。至少一次局面变化要迫使己方调整；变化应来自已经展示的信息。
4. **军团由不同职责组成。** 红骑士的强大可以通过部下为他创造窗口、他为部下解除压力来表现。决定性动作有铺垫，配角有可辨认的贡献。
5. **目标定义胜利。** 守住、救出、护送、突破、延缓均可成篇；结尾交代目标、人员、阵地与遗留问题。无需每次清空所有敌人。
6. **经验与代价连续。** 人员受伤、阵地受损、装备损耗、一次判断带来的后果，进入后续记录。只有用户确认的内容才进入正式项目状态。
7. **严肃行动中容纳短促人味。** 幽默可来自装备申请、分工、性格与战场反应；保持短句，并让它影响或回应眼前行动。具体台词与语气另行创作。
8. **简约形式需要精细执行。** 二维轮廓、符号单位、克制纹理足够；线条、字、光、状态变化、图卡与镜头需要统一，避免用写实细节替代这些工作。

证据较强的共同主题：空间与分工影响结果（#001、#003、#006）；专用装备将限制变成行动条件（#002、#004、#007、#009）；角色与后果连续（多集出演/伤亡表及#004、#005）；战场信息存在不确定性（#003、#008、#009）。

需要保留的差异：#002侧重潜入，#005侧重护送与火力释放，#008侧重识别与疏散；#006一队成功撤回，#009没有一队全灭。由此不采用统一的“菜鸟送死→规则卡→高手无伤”公式。开场悬念、行动、复盘、收束可以根据任务重新组合。

### 转译到红骑士

这是表现方向，不新增能力或数值：

| 原片的方法 | 红骑士方向的转译候选 | 输入条件 |
|---|---|---|
| 小队各自承担职责 | 指挥、掩护、侦察、侧翼、预备队的关系可视化 | 只使用作者已确认存在的单位与职责 |
| 封门、控车、分隔交战区 | 表现路口、门洞、通路、阵线与增援路线 | 地形必须在镜头中建立，防御机制另依已有规则 |
| 道具使用前展示条件 | 把已经存在的装备或布防手段画成简短图卡 | 缺少能力条件就标待定，不能临时发明解法 |
| 专业行动夹杂角色短句 | 用命令、报告、接替与事后记录表现军团性格 | 台词可作为演示候选，身份和世界事实需有来源 |
| 出演与伤亡账本 | 战后名单、阵地状态、任务结果、下一步问题 | 演示结果不能自动写回正史或真实模拟统计 |

红骑士也不必每集亲自终结。若主题是布防，重点可落在“部署为何成立、哪里承压、何时调动、谁完成接替”；若主题是冲击，重点可落在“谁创造了通路、何时下令、冲击之后如何接应”。这些是镜头要回答的问题，不预定战斗结果。

## 制作原则与验收标准

以下尺寸、颜色和时长均为本项目的**拟定制作参数**，不是测出的原作者规范；后续获准优化时先做样片再定。

### 画面：二维、简约、精细

- 场景以平面几何、少量家具/障碍剪影、低对比表面变化组成。装饰应让门、路径与遮挡更容易辨认。采用克制的边缘亮度、局部光晕与暗角，不追求摄影质感。
- 原片#002起有完整的“战术终端”外壳：细边框、刻度、指示条、底部格栅与暗品牌。下部留暗是仪器造型的一部分。此前简单认定其为无效留白不准确。外境可选择自己的记录器或战报装帧语言，先做统一壳体，不生搬现代终端的标识。
- 拟定主色：炭黑背景、灰白结构、暗金友方、绯红威胁；蓝绿只用于少量辅助信息。敌我还需以轮廓、文字或图标区分，不能只靠颜色。红骑士作为己方时，其赤色角色特征和敌方警示色必须另设区分方案。
- 单位至少能读出身份、朝向和关键状态；盾手、观察者等有职责符号。关键怪物可以有简化剪影，避免所有人永远都是同样的圆点。
- 地图、单位、墙体、文本、光效分层。界面在屏幕坐标绘制，场景在世界坐标绘制；视口变化后重新投影绘制线条和字。避免把低分辨率整张地图放大后作为近景。
- 输出1080×1920只是文件规格。真正验收的是：近景细线是否稳定、字是否清楚、轮廓是否锐利、光效是否吞掉信息、压缩后能否辨认职责。
- 第一轮候选字号以1080画布上正文28–36px、重点标题48–64px试排；重要线条约2–3px起试。最终以手机等效缩小预览能读清为准，不以参数代替检查。
- 纹理与光效优先低幅度、少量层次。队员/敌人、交互点、当前因果关系优先于装饰。界面状态条应有可解释来源，避免伪造一排不断跳动的“专业数据”。

### 叙事与镜头：让行动解释规则

- 一个短片优先讲清一个任务和一组关键限制。开头给出异常或难题，尽早建立空间；图卡只保留本集会真正用到的条件。
- 使用“信息→判断→动作→反馈→调整→结果”的因果链。允许撤退、分兵、救援、等待等动作，不把“持续攻击”当作唯一内容。
- 每个主要镜头只突出一个变化。全景负责位置关系，近景负责关键动作；切回或移动后给观众重新定位的依据。字幕不得盖住正在解释的门、路线、单位。
- 道具卡采用简化线稿加用途/限制，随后回到地图兑现。持续登场的熟悉装备可略写，新限制才值得展开。
- 角色高光卡只在已经发生可识别贡献后出现；它强调贡献，不能代替动作。战后表明确区分阵亡、受伤、撤离、任务失败与任务成功。
- 原片约95–155秒，不能据此认定58秒最合适。后续先按内容试排约90–150秒，关键动作可短暂拉长，长距离移动可明确跳时。战斗时间与影片时间分别记录。
- 配音、配乐和音效风格尚待原片核听。当前只能提出我方候选：命令短、报告具体、效果跟随动作；不得标注“已还原原片声音”。

### 从演示发展为模拟时的运行逻辑

当前《无声钟楼》是写死路径和时间点的动画。后续应将三个层次分离：

1. **输入层**：作者确认的规则、地图、单位、布防与任务目标；临时假设单独标记。
2. **结果层**：演示可用人工编排事件；真实模拟必须由规则引擎产生行动和裁定，并保存随机种子、行动者、位置、原因与前后状态。表现层不得为了好看改变裁定。
3. **表现层**：读取同一事件记录，生成位移、朝向、关键状态、字幕、图卡和镜头。可以慢放/跳时，但要保持因果顺序。

风味研究阶段不移植参考片的伤害、生命、射程、冷却和装备数值。界面优先显示职责、位置、命令、目标与已发生状态；引用已有模拟结果时也只能使用其明确支持的数据。

### 后续执行顺序与质量门槛

当前停在参考研究，以下为待完整阅片条件满足后执行的顺序：

1. 补足可靠音轨核听和关键动作连续时序观察，更新覆盖记录。
2. 从作者材料抽取本次可用人物、装备、地形与任务；列明缺口，不自行补成正式规则。
3. 先出单帧风格板：全景、局部动作、装备卡各一张，检查统一视觉语言。
4. 再做一个约10秒的同场景动作样片，验证移动、遮挡、朝向、动作反馈与近景清晰度。以原片可访问帧和我方样片并列检查，不能只比较输出分辨率。
5. 视觉通过后再铺完整事件表与镜头；演示与真实模拟标明类型。导出后检查开头、关键动作、结尾、字体、声画及全片解码。

每轮必须回答五个验收问题：静音能否看懂发生什么？暂停能否看清谁在哪？结束能否解释为何成功或失败？不同角色是否各有贡献？这次结果留下了什么？声音验收需另补可靠听辨，不能由静音检查替代。

当前旧样片的差距仍包括：底图位图放大导致近景粗、符号和图卡体系不足、人物持续性不足、敌人的回应过于单线、界面装帧不统一。换成更写实的地图不会自动修复这些问题；本轮仅记录，不抢先改片。

## 可复用 Prompt

以下均由本次研究重新编写，是给外境后续制作使用的提示词，**不是原UP的实际prompt**。使用时把花括号替换为真实材料；未知内容保留未知。涉及声音的描述是我方候选，等待原片核听后再修订。

### P0：总控 / 制作纲领

```text
为《外境》的红骑士相关战斗与布防制作一支二维战场记录短片。
输入：{作者确认材料}、{本集任务}、{地图与单位}、{前集后果}、{参考观察记录}。
制作状态：{视觉研究/演示动画/规则模拟回放}；当前阅片条件：{是否满足}。

风味目标：专业分工、空间因果、敌方应对、临场调整、代价延续。
视觉目标：简约俯视战术地图、精细轮廓与排版、少量局部光效、统一图卡和战报装帧。
只使用输入中已确认的能力、装备和世界事实。缺口单列，演示假设明确标记。
本阶段不借用参考视频的数值，不编造伤害、生命、射程或胜率。
先验证任务与空间因果，再安排镜头；输出尺寸不能作为画质达标的证据。
同一个角色的职责、状态和此前后果保持连续。敌方至少有一次基于已展示条件的应对。
结尾交代任务、人员、阵地和遗留问题，不强制歼灭所有敌人。
若用户规定的完整阅片条件未满足，只整理研究和制作文档，不执行成片优化。

依次输出：材料状态表；一句话任务；因果链；职责与空间关系；视觉方案；
事件/镜头表；待核实项；验收方法。明确区分原片观察与本次建议。
```

### P1：故事与战术风味

```text
依据{总控纲领}和{已确认材料}，整理一个可通过地图动作讲清的行动故事候选。
先列任务成功条件、可用信息、未知信息、双方目标、各角色职责。
再按“信息—判断—动作—反馈—调整—结果”写6至10个节拍。
每个节拍填写：谁知道什么；为什么这样做；地图上如何表现；对手如何回应；
付出什么代价；下一步因此发生什么。不得依靠未出现过的能力临时解围。
让一次前期准备产生可见回报，让至少两名不同职责角色互相创造行动机会。
允许专业撤退、护送、守住和救援；不固定套用两队对照。
短对白用于命令、报告或性格反应。不要把规则说明拆成角色长篇讲话。
末尾列出正式材料依据、演示候选和未解决缺口。此步骤不写回正史。
```

### P2：布防与空间审查

```text
输入{地图}、{单位职责}、{任务目标}、{已有规则}和{故事节拍}。
将每次部署标在地图上，注明观察方向、控制入口、接替关系、预备位置和撤离通路。
对每段关键行动检查：起终点连通吗？门是否已开？墙体和障碍是否挡路/挡视线？
角色从哪里得知敌情？谁在其移动期间承担原职责？敌方为何进入或避开该位置？
分别输出己方可见信息与全知示意，不让角色凭镜头全知行动。
不自行设定射程、速度、伤害、掩体收益或成功概率。规则不足处标为待定。
输出“位置关系图说明+行动顺序+因果缺口+最小修正”，不通过增加超能力解决缺口。
```

### P3：美术 / 单帧风格板

```text
制作{具体场景}的二维俯视战场记录风格板，供代码渲染或矢量绘制执行。
画布1080×1920，提供全景、局部动作、装备卡三个状态。
场景采用几何结构、少量剪影道具、低对比表面变化；以可读通路与障碍为第一层。

装备信息作为独立图卡或事件；世界碰撞半径与画面大小分离，先读取导航状态再绘制。
拟定炭黑/灰白/暗金/绯红体系，辅助蓝绿少量使用；另解决红骑士己方身份的区分。
设计自己的战报装帧，包括边框、标题、阶段、任务和简短状态，保持克制。
文字与符号在最终画布清晰绘制；近景重新绘制几何与文本，避免低清底图整体放大。
光分为环境暗部、可解释的照明和少量事件强调；遮挡服从地图结构。
输出分层清单、字体层级、图标规则、色彩用途与三张状态图的构图说明。
不生成假文字作为最终界面，不通过增加写实材质改变既定简约方向。
```

### P4：动画实现 / 事件回放

```text
依据{风格板}、{地图结构}和{事件记录}实现可复用的二维回放。

对镜头缩放后的几何、文字和符号按输出尺寸绘制，保证近景清晰。
每个事件包含id、战斗时间、行动者、位置、朝向、事件类型、前后状态、原因及依据。
数据来自{人工演示编排/指定规则引擎}，在界面与说明中如实标明类型。
表现层仅负责播放，不能新增伤害、改变胜负、补造能力或暗改事件顺序。
关键动作提供准备、发生、反馈三个可辨认阶段；状态变化与事件保持一致。
先输出静态预览与约10秒动作样片，检查路线、遮挡、朝向、字和近景，
```

### P5：镜头、字幕与候选声音方案

```text
把{事件表}转成镜头表。每行包含：影片时间、战斗时间、景别、关注点、
可见动作、信息变化、字幕/对白、声音候选、前后空间衔接。
先建立地理关系，再强调关键动作；返回全景时提供定位依据。
每个镜头突出一个主要变化；字幕避开当前关键对象；规则卡只解释接下来要用的条件。
移动可跳时，决定性动作可展开，但分别记录两种时间，不伪造同时发生。
声音候选按命令、动作反馈、环境三类列出，注明“原创制作建议，原片声音未核实”。
```

## 已有样片与源文件记录

《别让它听见你》是用户授权编排的独立虚构故事，用于验证外境能否采用俯视地图、单位标记和任务复盘形式制作视频，不属于正式世界设定。

当前修订片：`外境_无声钟楼_简约修订.mp4`，1080 × 1920，30 fps，58 秒，H.264 / AAC。早期成片与过程预览已移至相邻交付目录的“已停用版本”。

三人小队在钟楼营救巡灯人。空甲被击碎后重新聚合；斥候通过碎石声发现它会追踪声音。小队用发条响器诱敌入侧室，关门后营救。响器提前停止，守卫撞开门闩；前卫把剑鞘投向大厅另一端，利用第二声源掩护撤离。守卫未被永久消灭，任务目标达成。

参考零号处置组的公开投稿，仅借鉴俯视地图、标记运动、道具卡和战报式结构。最终地图、界面、动作效果及环境音均在本目录程序中制作，没有使用该 UP 的视频、图像、角色或音频素材。旁白使用 Microsoft Edge 在线合成语音，主体为 Yunxi，短对白为 Yunjian；通过开源 edge-tts 生成，不克隆真人声音。

用户明确选择简约风格，因此最终不采用曾测试的写实地图。使用低对比平面场地图、少量桌椅与柱子、墙体遮挡的灯光。新增局部镜头、近景时的缩略地图、攻击碎裂与复原、落闩、撞门、破门和投掷等动作。常驻提示缩减为目标、阶段和三人状态；片长从 79 秒压至 58 秒。

这是预先编排的动画时间轴，尚未实现可交互玩法、寻路或战斗裁定。它验证成片形式与素材复用方法。

## 重新生成

在项目根目录运行：

```powershell
python 'WestMarch\制作验证\无声钟楼\源文件\生成自然旁白.py'
python 'WestMarch\制作验证\无声钟楼\源文件\render.py'
```

依赖：Python、Pillow、NumPy、FFmpeg；重新生成自然旁白需 edge-tts 和网络，已有音频可直接重新渲染。edge-tts 当前安装于系统临时目录 waijing-tts，生成脚本也支持已安装在 Python 环境中的版本。仅生成预览帧可为渲染命令追加 `--stills`。

故事旁白与时间点保存在 `源文件/旁白.json`；地图、单位路径、特效、界面、混音和渲染保存在 `源文件/render.py`。修改这些文件即可复用下一支短片。
