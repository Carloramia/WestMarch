# 外境｜神秘学与民俗调研指南

本文件是外境项目跨主题的资料搜索与整理指南。它指导后续调研，不构成世界观定稿、规则或对任何传统的统一解释。已有世界、角色、规则和材料研究仍分别维护于 [外境](外境.md) 所列的主题文件；本文件只维护搜索方法，不重复存放各主题调研成果。

## 正式工作目录与研究语境

正式目录为 WestMarch。项目纲领和内容目录见[外境](外境.md)，本文维护后续跨主题调研方法。当前研究结合以下已明确方向展开。

- 第一个开放地区是未亡地，聚落在灾害中仍有活力，重点研究维生、庇护、劳作、税收、献祭、流动与灾后生存的具体实践。
- 七准则性相为刃、枝、杯、月、夜、星、铸。枝替换心、星替换尘、夜替换冬。星辰与星币、圣杯溢出与渴望作为定向检索意象，领域划分继续标明候选身份。
- 三柱呼应卡巴拉，外境的严厉强调内收、界定与边界，慈悲强调发散、无限与模糊。查证时明确历史传统、后世阐释与项目改写的层次。
- 角色成长联系消化、晋升、恩主和仪轨。材料、协作者、场所、供物及先行仪式均应作为研究问题，先查具体案例再讨论组合。
- 共享世界支持跑团、增量经营、写文与绘画。聚落、建筑、藏物、疾病转移、丧葬和知识传递的研究应记录行为后果，便于分析长期建设与共创。
- 战斗设计已安排后续移交，当前研究继续遵循构筑有深度、实际行为简单、场地行为有效、高位格有所体现的要求。

参考资料和下载许可见[参考资料索引](参考资料/索引.md)，地区现行内容见[未亡地](未亡地.md)。

## 调研目标

围绕性相、神明、仪式、材料、物件、地点及意象，寻找有历史或当代实践依据的神秘联系。关注符号背后的行为与关系：谁在何时何地，以何种材料对谁做了什么，参与者如何理解其作用，物件后来发生了什么。

优先探索具备强烈民俗、地方传说与仪式细节的材料，避免停留在大众化的单词对应表。冷门不是可信的代名词，也不为追求新奇排除重要的常见来源；关键是具体、可追溯，并能进一步系统比较。

## 范围与优先级

1. **炼金术与炼金图像**：优先研究不同作者、地区和时期的文本、材料、器具、操作、颜色、天体和图像。区分实际操作、寓言与后世解释；不假设所有炼金传统共用一套固定符号表。
2. **强民俗传说与神秘实践**：与炼金术并行优先，关注地方民间魔法、圣井与祈愿物、疾病转移、建筑藏物、防邪、誓约、丧葬与祖先。要求有魔法、超自然、神圣或仪式联系的具体证据，不把所有民俗自动视为神秘学。
3. **神秘主义与秘教**：犹太卡巴拉、基督教神秘主义、伊斯兰神秘主义、赫尔墨斯主义、占星术与近代西方秘教分别研究；注意各传统内部差异，不把近代西方改写倒推成犹太教或其他宗教整体的教义。
4. **地域神话与宗教实践**：提高古埃及、巴比伦及其他美索不达米亚传统、美洲各地区传统的参考优先级。具体标明文化、地区、时代与来源，玛雅、纳瓦特尔、安第斯等不得混为一个体系。
5. **古典神话**：希腊、罗马适度补充与对照，不默认作为唯一或主要来源。
6. **近现代解释**：荣格、神智学、当代神秘主义和现代作品可以参考，明确作者与年代，区分其创新解释和所引用的历史材料。

优先级是研究资源分配，不是事实可靠性排序。先前讨论夜、星、月、沙只是实例，本指南不以任何单一性相为中心。

## 检索与验证流程

1. 确定对象和边界：它是物质、物件、行动、神明、天体、地点、图像还是隐喻；列出名称、别名、原语言及可能的混淆词。
2. 从炼金术和强民俗实践两条线并行搜索；按需要进入神秘主义、地区宗教与古典文献。先找具体案例，再比较，不先预设对应。
3. 优先找可定位的原典、历史手稿、仪式或田野记录、可核实的器物与考古报告；辅以大学研究、博物馆说明和研究著作。
4. 记录具体传统、地区、年代、参与者及其目的；明确是实践者自述、原始文本、研究者推断还是现代解释。宗教团体与实践者的解释应标明立场与语境。
5. 回查引文、版本、图像出处、馆藏说明和译名；无法直接读到原文时说明，不将摘要或搜索片段冒称全文核读。
6. 按相似性比较机制与差异；不同文化出现类似物件，不自动表示存在传播、共同起源或相同含义。明确区分关联、可证实传承和作者自己的创作推导。
7. 留意学术争议、资料局限、旧文献的时代偏见，以及活态传统自身的声音；必要时查阅对《金枝》等经典研究的批评，不能把某套理论当普遍定律。
8. 输出写入现有对应主题的唯一文件；确需独立主题时再建立文件。不创建按日期、批次重复的版本目录或汇总副本。研究方法更新直接修改本 README。

## 重点检索母题

以下是检索路径，不是已证实的普遍法则；每次需找到具体地区、个案和出处。

- **接触、替身与转移**：布条井、疾病转移、树木、衣物、毛发、姓名与替身；对照接触、相似与地方实践者自己的解释。
- **腐败、消散与变化**：布条腐烂、炼金黑化与其他材料变化；区分状态消退、旧形态终结、再生及完全消亡。
- **避邪、隐藏与边界**：巫术瓶、藏鞋、门槛、墙体和烟囱；区分实物出土事实与其神秘用途的推断。
- **圣地与供物**：圣井、祈愿树、遗留物、硬币树；研究献纳、疗愈、记忆和地点随时间的变化，不假定所有参与者意图相同。
- **誓约与束缚**：结绳、名字、容器、界石与解除；具体核对保护、记忆、限制或治疗等不同用途。
- **遗骨、祖先与遗忘**：名字、遗物、埋葬、死后旅程、第二次死亡；区分死亡、不可见、被遗忘与不存在。
- **炼金过程与神秘材料**：火、炉、容器、溶解、凝聚、黑化、白化及天体金属；核查具体文本与版本，不将物理工艺直接等同精神变化。

## 输出与资料卡

每项研究优先形成表格：意象／材料｜具体指向｜地区与时代｜文本、物件或实践｜来源｜证据类型与不确定性。需要至少三个指向时分别给出可核查来源；资料不足时如实说明，不凑数。

随后记录：反复出现的联系、不同传统之间的差异、未证实的流行说法，以及（用户需要时）单列的外境创作启发。创作建议不得冒充历史事实或作者已确认设定。

```text
主题与别名：
传统／地区／时代：
来源类型与具体位置：

实践者或原典描述的联系及结果：
材料、物件或地点后续的变化：
研究者解释、不同版本与争议：
已核实内容／推测／现代再解释：
可比较案例与是否存在可证实传承：
来源链接与访问情况：

```

## 已核实的起点

- [爱丁堡大学：苏格兰布条井与圣井传统](https://era.ed.ac.uk/server/api/core/bitstreams/9b7aaa28-fb25-4957-87da-e56f235cf41a/content)：研究将部分布条实践与疾病转移和布条腐烂的类比联系起来，不代表每处圣井或每位参与者的同一理解。
- [剑桥博物馆：家庭保护与隐藏物](https://www.museumofcambridge.org.uk/collections/folklore-house-protection-and-concealment/)：藏鞋、瓶和建筑位置可作考古与民俗调查入口；个案用途仍需核实。
- [大都会博物馆：炼金术、科学与装饰艺术](https://www.metmuseum.org/de/perspectives/alchemy-science-making-marvels)：炼金术与工艺、材料和物质转化的历史关系。
- [牛顿炼金手稿项目](https://newton.dlib.indiana.edu/text/ALCH00063/normalized)：可查炼金术文本；具体术语需结合上下文与版本。
- [Bouveresse：维特根斯坦对弗雷泽的批评](https://onlinelibrary.wiley.com/doi/10.1111/j.1467-9329.2007.00373.x)：提供审视《金枝》解释方法的入口。
